# CDM Project Page

Project website for **Contrastive Distribution Matching for Amortized
Sequential Monte Carlo in Discrete Diffusion**.

## Local preview

```
cd cdm_website
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
